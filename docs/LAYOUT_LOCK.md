# Layout lock (Nuggets Desk, launched 2026-09-30)

Cloned from the approved Broncos Desk layout (locked 2026-09-23). Do not redesign without an explicit user request. Daily runs update content only unless fixing a real bug.

1. **Banner**: compact centered CSS `.nuggets-banner` (DENVER NUGGETS / gold rule / JUST THE FACTS + corner accents in gold with a thin sunshine-red stripe) above the brand/nav row. Not image-based; not 2× height.
2. **Rail + main**: full-width flush-left `.page-shell`; `.northwest-rail` beside `<main>` (`clamp(15rem, 20vw, 19.5rem)`, ~1.05rem type, ~0.4rem left pad). Keep it flush to the left edge of the gold page.
   - Tile 1 `aside.northwest-standings`: Northwest Division standings (Thunder, Nuggets, Timberwolves, Trail Blazers, Jazz) ordered by current division rank. Columns Team / W–L / third column (PCT during the season; last season's record while everyone is 0–0). Nuggets row `tr.is-den`. Title links to ESPN division standings (new tab).
   - Tile 2 `aside.northwest-standings.northwest-standings--odds`: Team / Div / Title American odds (Nuggets row `is-den`), muted source line with book + "as of" time in MT. 0.75rem gap under tile 1.
3. **Chrome / palette** (`:root` in styles.css): page `--gold #FEC524`, white tiles, header/footer `--navy #0E2240`, links `--navy-soft #1D428A`, highlight `--gold-soft #fff8e1`, badge text `--gold-deep #7a5a00`, hover/kicker accent `--red #8B2131` (sparingly). **Never use gold as text on white** (1.6:1 contrast); gold is for backgrounds, rules, borders and bars only.
4. **Card order in `.grid`**: Record (span-2, with last-game/last-season writeup) → Last game (span-2) → Next | Sportsbook odds (one column each) → Kalshi (span-2, separate from sportsbooks) → Injuries (span-2) → Upcoming (span-2, next ~5–6 games incl. preseason; each game row ends with a small pill `a.ticket-link` "Tickets" link, see rule 8) → Ball Arena & team news (span-2) → Championship odds top 5 West/East (span-2). No weather card.
5. **Honesty rule**: never fabricate figures. When a number isn't available, say so on the card using `<span class="unavail">…</span>` (e.g. "Lines not posted yet"). Every card ends with a `.source-row`; odds and markets carry an "as of" time in MT.
6. External links use `target="_blank" rel="noopener noreferrer"`; same-site links stay relative.
7. Archive: prior home page is frozen to `docs/archive/YYYY-MM-DD.html` (fix relative paths to `../styles.css`, `../index.html`), newest first in `docs/archive/index.html`.
8. **Upcoming ticket links** (added 2026-09-30): every game row in the Upcoming card carries `<a class="ticket-link" href="…" target="_blank" rel="noopener noreferrer" aria-label="Tickets: …">Tickets</a>` at the end of the `<li>`. Style is fixed in styles.css (skyline-blue `--navy-soft` text + 1px border pill on white, ~0.72rem bold; hover fills skyline blue with white text). No gold text. URLs must be real and verified: home games (Ball Arena, or preseason at CU Events Center) use the specific game's link published by the Nuggets (nba.com/nuggets/schedule ticket data → Ticketmaster event, or CU Athletics' event listing for Boulder), else https://www.nba.com/nuggets/tickets; road games use the specific event link published on the host team's official nba.com schedule (Ticketmaster/SeatGeek), else the host team's official nba.com/<team>/tickets page. Never guess event IDs; never use resale affiliate links (e.g. ESPN's Vivid Seats links). The source-row notes which sellers are used.
9. **Custom domain**: `docs/CNAME` (`nuggets.petecarr.com`) must stay in the repo; the domain is live.
10. **Site nav** (added 2026-09-30; Roster added 2026-09-30; Hall of Fame added 2026-09-30): every page's `nav.nav` has exactly five links, in this order: **Home, Schedule, Roster, Archive, Hall of Fame**. Paths are relative: `index.html` / `schedule.html` / `roster.html` / `archive/index.html` / `hall-of-fame.html` from docs root, and `../index.html` / `../schedule.html` / `../roster.html` / `index.html` / `../hall-of-fame.html` from `docs/archive/`. The generator templates (`tools/schedule_template.html`, `tools/roster_template.html`) carry the same five links. The current page's link carries `aria-current="page"`, styled as a white pill with navy text (`.nav a[aria-current="page"]`). Pills never break internally (`white-space: nowrap`) and the row wraps on narrow screens (`.nav { flex-wrap: wrap }`, added with v=nuggets-4). When index.html is frozen into the archive, remove `aria-current` from the snapshot's nav. Stylesheet link is `styles.css?v=nuggets-4` (`../styles.css?v=nuggets-4` in archive/); bump the version only when styles.css changes (and then on every page and template).
11. **Schedule page** (`docs/schedule.html`, added 2026-09-30): uses the same banner, header and footer as Home. There is no Northwest rail: `.page-shell` > `main.main.sched-main`. Page order:
   - Hero: kicker "2026–27 season", h1 "Nuggets schedule & results", a deck with game counts, the regular-season and preseason records, and "As of … MT".
   - One `section.card.sched-month` per group: **Preseason first**, then each regular-season month in order (October → April). Postseason sections go after April if the team qualifies.
   - A closing "Sources & notes" card with a `.source-row`.
   - Each month is a `table.facts.sched-table` inside `.table-wrap`. Columns: Date (MT) · Opponent (`vs` home / `@` road, plus an optional `.sched-tag` pill such as "Emirates NBA Cup · West Group A", "NBA Mexico City Game" or "AWS NBA Rivals Week") · Venue (arena + `.sched-city`) · Time (MT) / result · TV · Tickets.
   - Home games are `tr.is-home`: pale-gold `--gold-soft` background plus a 3px gold inset bar. Road rows are white.
   - After a game, the time becomes the result: `<span class="sched-w">W</span>` (green) or `<span class="sched-l">L</span>` (sunshine red), then the score (DEN first, "(OT)" if applicable), then the running record `(W–L)` in `.sched-rec`. Preseason and regular-season records are counted separately.
   - TV: national networks plus the Nuggets-side broadcast (Altitude/ALT2/KTVD/KUSA) from nba.com schedule data. If nothing is listed, show `<span class="unavail">TBD</span>`.
   - The Tickets column holds `a.ticket-link` for upcoming games only; completed games leave it empty. Links follow rule 8.
   - Mobile (<42rem): the table collapses to stacked rows with `data-label` captions.
   - Unscheduled games (NBA Cup-dependent) are noted in December with `.unavail`. Never invent dates.
   - Generator: `tools/build_schedule.py`, which uses `tools/schedule_template.html` and is not published. It pulls ESPN team-7 schedule (seasontype 1 and 2, season=2027) for the list and results, nba.com/nuggets/schedule for TV and the Nuggets' own ticket links, and each host team's official nba.com schedule (static `__NEXT_DATA__` or a headless-Chrome render) for road ticket links. If no game link is published, it falls back to `nba.com/<team>/tickets`. It writes `/workspace/nuggets-data/schedule-YYYY-MM-DD.json`.
12. **Roster page** (`docs/roster.html`, added 2026-09-30): same banner, header and footer as Home; no Northwest rail (`.page-shell` > `main.main.sched-main.ros-main`). Page order:
   - Hero: kicker "2026–27 season", h1 "Nuggets roster", a deck with the player count and the split by contract type (standard / two-way / non-guaranteed camp), "As of … MT", and a legend of the tags.
   - "Players" card: one `table.facts.ros-table` inside `.table-wrap`, grouped by position (Guards → Forwards → Centers, navy `tr.ros-group` header rows with counts), sorted by jersey number within each group. Columns: # · Player (links to the ESPN player page, new tab) · Pos · Ht · Wt · Age · Exp (yrs; nba.com, "Rookie" = 0) · College / pre-draft · 2026–27 cap hit.
   - Tags in the Player cell: `span.ros-tag.ros-tag--tw` "Two-way" (skyline-blue border and text on white), `span.ros-tag.ros-tag--camp` "Exhibit 10" or "Camp deal" (gold-deep text on gold-soft with a gold border). Non-standard rows (`tr.ros-two-way`, `tr.ros-camp`, `tr.ros-camp-e10`) get a light `--paper` background. Injuries show `span.ros-inj` (sunshine-red text and border on white) with ESPN's status and the date ESPN last updated it. No gold text.
   - Cap hit column: Spotrac 2026–27 cap hit for standard contracts, checked against Basketball-Reference. Two-way rows say "Two-way (no cap hit)" and camp rows say "Non-guaranteed" in `.unavail`. Footnotes in `p.ros-foot` under the table: `*` marks vet-minimum deals (with actual salary) and source differences (e.g. Gordon incentives); `†` marks jersey numbers that differ on nba.com (ESPN shown). If cap figures can't be verified, drop the column rather than guess.
   - Cards after the table: "Coaching staff" (`dl.data-list` from nba.com, head coach checked against ESPN) → "Mascot" → "Injury report" (ESPN injuries; flag stale dates) → "Sources & notes" (`.source-row`).
   - **Mascot card (permanent, added 2026-09-30)**: `section.card.ros-mascot#mascot` with a one-row `table.facts.ros-table` for Rocky (# — because the Nuggets list no number · Name · Pos "Mascot" · Ht 5′10″ · Wt 154 lb · NBA debut Dec. 15, 1990 · Birthplace "Rocky Mountains" · Honors "Mascot Hall of Fame, Class of 2008"), a `p.ros-foot` and a `.source-row`. It is static HTML in `tools/roster_template.html`, outside `{{ROWS}}`: Rocky is never counted as a player, never in `roster_contracts.json` and never part of the ESPN/nba.com check. `build_roster.py` exits with TEMPLATE ERROR if the card is missing. Do not remove it.
   - Mobile (<42rem): rows stack. Number and name sit on the first line, then Pos/Ht/Wt/Age/Exp inline, then College and Cap hit with `data-label` captions.
   - Generator: `tools/build_roster.py` (template `tools/roster_template.html`, contract data `tools/roster_contracts.json`; not published). It pulls the ESPN team-7 roster and injuries plus nba.com/nuggets/roster `__NEXT_DATA__` (player-list check, experience, jersey check, coaches). It stops with ROSTER MISMATCH unless both lists agree and every player has a contracts entry (`--allow-mismatch` publishes anyway and lists the mismatch). It writes `/workspace/nuggets-data/roster-YYYY-MM-DD.json`.
